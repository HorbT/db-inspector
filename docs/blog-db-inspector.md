## DB Inspector 是什么？

**DB Inspector** 是一款面向数据库运维工作者的**智能巡检与健康评估工具**。它支持 **MySQL、Oracle、SQL Server、TiDB、StarRocks、PostgreSQL** 六大主流数据库，只需简单配置连接信息，即可一键完成全面的数据库健康检查，并生成专业的可视化巡检报告。

更重要的是，它内置了 **AI 智能分析引擎**，能够针对每一个巡检指标给出专业评估和改进建议——相当于你身边多了一位 7×24 小时的数据库专家。

## 核心功能一览

### 一、一键自动化巡检

告别手动登录数据库执行 SQL 的原始方式。配置好连接后，点击"开始巡检"，系统会自动执行针对该数据库类型的全套健康检查脚本，涵盖：

- 实例与版本信息
- 数据库大小与表空间
- 连接与会话状态
- 锁与阻塞分析
- 慢 SQL / 高消耗 SQL 排行
- 索引使用情况（未使用索引、缺失主键）
- 主从复制 / 流复制状态
- 参数配置与安全审计
- WAL / Redo 日志状态
- 缓存命中率与 IO 性能
- ...以及更多

**【截图位置：巡检执行界面，展示实时的巡检进度日志和结果】**

### 二、专业可视化巡检报告

巡检完成后，系统自动生成结构化的巡检报告。报告采用清晰的三级目录结构，每个巡检点独立展示，配有 HTML 表格、彩色标注，一目了然。

报告中每个巡检指标都带有分类标签和实时数据，不再是一堆枯燥的数字。

报告以 **SQLite 轻量数据库** 格式存储，体积小巧、便于归档、跨平台兼容。支持随时预览历史报告，对比不同时间点的巡检结果，轻松追踪数据库健康趋势。

**【截图位置：巡检报告预览界面，展示报告目录、数据表格和 CSS 美化的效果】**

### 三、AI 智能分析 —— 核心亮点

这是 DB Inspector 最与众不同的功能。

传统巡检工具只能告诉你"某个指标是多少"，但 DB Inspector 还能告诉你**这个指标意味着什么、风险有多高、应该怎么优化**。

在巡检报告的每个三级标题右侧，都有一个**"AI 分析"按钮**。点击后，系统自动提取该巡检点的全部数据，发送给 AI 模型（支持 OpenAI、Gemini 等），几秒钟内返回专业的分析结论和改进建议。

分析结果在鼠标悬停时以弹窗方式展示，不遮挡报告内容。**分析结果为每个巡检点独立缓存，软件关闭后自动清空**，保护数据隐私。

**【截图位置：AI 分析按钮在报告标题右侧的展示，以及鼠标悬停弹出分析结果的界面】**

你可以针对任意巡检点单独分析，比如：

- "锁和会话"巡检点 —— AI 会分析当前的锁等待情况、是否存在潜在的死锁风险
- "慢 SQL"巡检点 —— AI 会评估执行效率、给出索引优化建议
- "复制延迟"巡检点 —— AI 会判断延迟是否在安全范围内、是否需要扩容

相当于**给每个巡检指标都配备了一位专属 DBA 进行解读**。

### 五、报告管理与导出

所有巡检报告自动归档，支持按数据库类型、关键字搜索和过滤。报告可导出为**独立 HTML 文件**，便于分享给团队或领导汇报，无需安装任何额外软件即可在浏览器中查看。

**【截图位置：报告管理页面，展示报告列表、搜索过滤和报告预览】**

### 六、轻量高性能

经过深度的性能优化，软件在内存使用上做到了极致克制：

- 启动后 Python 后端插件**按需懒加载**，只在实际使用时才加载对应的数据库驱动
- SQLite 报告数据采用**分页按需读取**，避免一次性加载全部数据行
- ReportDB 引擎实例采用 **LRU 缓存复用**，同一报告多次操作共享 WASM 内存

**实测空载内存占用仅约 800MB**，远低于同类 Electron 桌面应用。

## 解决了数据库运维中的哪些痛点？

### 痛点 1：手工巡检效率低下

> "我们组三个人维护 200+ 个数据库实例，每个月轮一次巡检就要花整整一周。"

**解决方案**：一键自动化巡检，5 分钟完成一个实例的全面检查，效率提升 50 倍以上。

### 痛点 2：巡检标准不一致

> "老张巡检喜欢看慢 SQL，小李更关注锁和索引，大刘只看磁盘使用率——换个 DBA 等于换一套标准。"

**解决方案**：内置标准化的巡检脚本体系，覆盖所有关键指标，确保每个实例的巡检维度完全一致。

### 痛点 3：巡检结果难以沉淀和对比

> "上个月的巡检报告放哪了？现在的 IO 性能比三个月前是提高了还是下降了？"

**解决方案**：所有巡检报告以 SQLite 轻量格式存储，支持历史归档、关键字搜索、按时间排序。未来版本还支持**报告对比**功能。

### 痛点 4：发现问题后不知道如何优化

> "巡检脚本跑出了 50 条结果，我知道有问题，但到底是哪个问题最严重？该怎么修复？"

**解决方案**：AI 智能分析功能，为每个巡检指标提供专业解读和优化建议。不是简单告诉你"你的慢 SQL 有 10 条"，而是告诉你"第 3 条慢 SQL 缺少联合索引，建议在 (user_id, create_time) 上创建索引，预计可降低 90% 的查询时间"。

### 痛点 5：多数据库类型环境管理混乱

> "公司同时有 MySQL、Oracle、PostgreSQL、TiDB，每种数据库的巡检方案都不一样，切来切去累死了。"

**解决方案**：统一的管理界面，一键切换数据库类型。插件化设计确保每种数据库都有专属的巡检脚本和报告模板，无需手动适配。

### 痛点 6：数据库被"救火式"运维

> "每次都是出问题了才去查，从没做预防性检查。"

**解决方案**：培养"防火式"运维习惯。定期执行巡检，建立健康基线，AI 辅助分析趋势，在问题发生前预警。
